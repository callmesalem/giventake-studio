How it is put together

Hand-written HTML, CSS and JavaScript. No framework, no build step, no dependencies at runtime. Deployed as static files, so there is nothing to patch and nothing to go down.

The rules we hold ourselves to

It works without JavaScript

Every word renders with scripting switched off. Animation is opt-in, layered on top, never load-bearing.

Nothing is tracked without permission

No cookies until a visitor actively agrees. Where advertising tags exist, Accept and Decline get identical weight.

Claims are checked, not asserted

Automated checks run against a real browser on every change: contrast, keyboard access, structured data, page weight, reduced motion, tracking. A build that fails does not ship.

Nothing is invented

No stock imagery standing in for real work, no made-up ratings in the markup, no claim about a business we could not confirm with its owner.

Who built it

GivenTake Devs, an AI-native development studio working with small businesses, founders and growing teams. If you want a site that can publish a page like this about itself, that is the whole pitch.
