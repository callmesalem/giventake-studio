---

## Why this gets its own folder

The first thirty days decide whether a client is easy or difficult for the rest of the
engagement, and almost all of it is set in the first week: who decides, how fast they
respond, what channel we use, what "done" means, and whether anyone wrote down what
things looked like before we started.

Get those wrong and you spend the project negotiating. Get them right and the project
is mostly building.

**The one step that carries beyond this engagement** is the baseline measurement on
day 5. It takes ten minutes, and it is the difference between a case study that says
*"cut invoicing from five days to same-day"* and one that says *"the client was
pleased."* Only one of those wins work — and it's the reason the site currently has no
case studies at all.

## Split of responsibility

| Agents | Human |
|---|---|
| Send the welcome packet | The kickoff call |
| Chase access and credentials | Any scope conversation |
| Book and remind the kickoff | Recording the baseline numbers |
| Track the checklist and flag what's missing | Anything a client would want a person for |
| Send day-30 check-in draft | Sending it |

Per charter §1, agents run the sequence. They do not run the relationship.
